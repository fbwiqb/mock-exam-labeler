ㄷ + 한자 = 수학·연산 (± × ÷ ≠ ≤ ≥ ∞ √ ∫ ∑ ∝ …)
ㄹ + 한자 = 단위 (㎖ ㎗ ℓ ㎜ ㎝ ㎞ ㎏ ℃ Å …)
ㅎ + 한자 = 그리스 문자 (α β γ δ Δ λ μ π Ω …)
ㅈ + 한자 = 로마 숫자 (Ⅰ Ⅱ Ⅲ Ⅳ Ⅴ ⅰ ⅱ …)
ㅊ + 한자 = 분수 (½ ⅓ ⅔ ¼ ¾ ⅛ …)
ㅁ + 한자 = 일반 기호 (※ ☆ ★ ○ ● → ↑ …)
ㅇ + 한자 = 원·괄호 문자 (① ② ㈀ ⑴ …)
ㄱ + 한자 = 문장부호 (· ‥ … ¨ ′ ″ …) · ㅂ + 한자 = 선·괘선 (─ │ ┌ ┐ …)

사용법

  • 이미지 열기로 PNG·JPG를 불러옵니다. 캔버스에 그림 파일을 끌어다 놓아도 됩니다.
  • 이미지 저장은 라벨이 합쳐진 PNG, 프로젝트 저장(.melp)은 나중에 다시 편집할 수 있는 원본입니다.
  • 저장한 .melp를 열면 라벨·도형을 이어서 편집할 수 있습니다.
  • 맞춤·＋·－ 또는 Ctrl+휠로 확대·축소합니다.
  • 상단 누끼로 특정 색을 클릭해 투명하게 만들 수 있습니다(오차 조절 가능). 상단 캔버스로 그림 여백을 늘립니다.
  • 왼쪽 프리셋((가) A ㉠ ① …)을 누르거나 문구를 입력하면 추가 모드가 켜집니다.
  • 그림에서 가리킬 지점을 누른 채 라벨 둘 곳까지 드래그하면 지시선 라벨이 생깁니다.
  • 라벨은 드래그로 옮기고, 더블클릭하면 문구를 고칩니다. 방향키로 1px(Shift 10px) 이동합니다.
  • 모양 패널에서 글꼴·크기·여백·색·배경과 굵게/이탤릭/밑줄/외곽선을 조절합니다.
  • 수식 넣기 버튼으로 작은 편집기를 엽니다. 미리보기를 보며 식을 만듭니다.
  • _는 아래첨자, ^는 위첨자, 두 글자 이상은 { }로 묶습니다. 예: H_2SO_4, Ca^{2+}.
  • 전하·반응기호·연산자 버튼과 한글 IME 한자 단축키 안내(ㄷ=수학, ㄹ=단위 …)를 함께 제공합니다.
  • 넣기를 누르면 프리셋처럼 그림에 드래그해 배치합니다.
  • 라벨을 선택하고 표시를 켜면 가리키는 선이 생깁니다. 끝점(파란 핸들)을 잡아 미세 조정합니다.
  • 형태(직선/꺾은선), 선 종류, 굵기, 라벨 간격을 조절합니다.
  • 화살표를 켜면 가리키는 지점에 화살촉이 표시되며 모양과 크기를 정합니다.
  • 현재 서식 전체 적용으로 지금 서식을 모든 라벨에 한 번에 적용합니다.
  • 사각형·타원은 드래그해서 넣습니다.
  • 자유형은 점을 차례로 클릭하고, 처음 점을 다시 누르면 완성됩니다. (Enter 완성 · Esc 취소 · Backspace 마지막 점 취소)
  • 채우기·경계선 색은 스포이드로 그림에서 직접 찍을 수 있습니다.
  • 점을 찍거나 드래그할 때 루페가 우측 하단에 나타나 픽셀 위치와 색을 확대해 보여줍니다.
  • 라벨을 Ctrl(또는 Shift)+클릭하면 여러 개를 함께 선택합니다. 빈 곳을 드래그하면 사각형 범위 안의 라벨이 한꺼번에 선택됩니다.
  • 선택된 라벨은 점선 테두리, 기준 라벨은 굵은 파란 테두리와 모서리 점으로 표시됩니다. 기준을 바꾸려면 선택된 라벨 중 하나를 (Ctrl 없이) 그냥 클릭하세요 — 선택은 유지된 채 그 라벨이 기준이 됩니다.
  • 2개 이상 선택하면 상단에 맞춤 버튼이 나타나, 왼쪽/가로 가운데/오른쪽(좌우)·위/세로 가운데/아래(상하)로 기준 라벨에 맞춰 정렬합니다. 정렬 시 지시선 시작점도 라벨과 함께 이동합니다.
  • 3개 이상 선택하면 간격 버튼(가로·세로)으로 라벨 사이 간격을 균등하게 분배합니다.
  • 선택된 라벨은 함께 이동(드래그·방향키)·삭제·복제됩니다.
  • 도형은 드래그로 넣을 때 Shift를 누르면 정사각형·정원이 됩니다.
  • Ctrl+Z / Ctrl+Y — 실행 취소 / 다시 실행
  • Delete — 선택한 라벨·도형 삭제 · Ctrl+D — 라벨 복제
  • 방향키 — 1px 이동 · Shift+방향키 — 10px 이동
  • Ctrl+휠 — 확대/축소
  • 자유형 — Enter 완성 · Esc 취소 · Backspace 마지막 점 취소
